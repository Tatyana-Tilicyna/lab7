## Описание проекта
Адаптивная веб-страница презентационного сайта туристического агентства. Страница корректно отображается в Desktop- и Mobile-версиях, сохраняя структуру, визуальную иерархию и удобство взаимодействия при изменении ширины экрана.

### Реализованные требования:
- Использование семантических элементов HTML5.
- CSS Flexbox применён для компоновки Hero-блока, блока контактов (Footer), промо-баннера и списка технологий.
- CSS Grid применён для создания адаптивных сеток в разделах "Услуги", "Проекты" и "Команда" (Отзывы).
- Использование современных единиц измерения и функций: min(), clamp(), minmax(), fr.
- Реализовано автоматическое переключение макета при изменении ширины окна браузера (контрольная точка 768px).
- Реализовано ручное переключение между Desktop и Mobile представлениями через кнопки в Header.
- Отсутствие горизонтального переполнения и табличной вёрстки.
- Изображения подключены как отдельные элементы интерфейса, а не как единый фон страницы.

## Как запустить и пользоваться

### Локальный запуск
1. Скачайте или клонируйте этот репозиторий на свой компьютер.
2. Откройте файл index.html двойным щелчком в любом современном браузере (Chrome, Firefox, Safari, Edge).

### Проверка адаптивности
- Изменяйте ширину окна браузера: при ширине менее 768px макет автоматически перестроится в мобильную версию (одна колонка, бургер-меню).
- Используйте кнопки Desktop / Mobile в правом верхнем углу шапки (Header) для ручного переключения режимов отображения.
